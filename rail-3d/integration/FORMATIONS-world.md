# 世界版立體列車編組（2026-10-01）

紐約、東京沒有逐班派車資料，3D 列車一律用「路線標準編組（推估）」：節數與單車長取該路線常見的營運編組，不代表當班實際派車。跟車卡會顯示「N 節・推估編組」。

## 外觀

2026-10-01 起改用當地車型網格（`tools/fleet`，依維基百科尺寸與 Commons 自由授權照片程序化建模，細部仍是示意）。

**東京：全部 75 條路線、110 款網格。** 各線用哪些車型由 `tools/fleet/map_tokyo_fleet.py` 依 `docs/rolling-stock/catalog-2026-10.json` 產生：該線的主力車型權重 1、少數車型 0.3，每班車依車次號碼雜湊固定分配一款（`formations.js` 的 `pickMesh`），比例是推估，不是當天實際派車。直通運轉路線因此會混跑各公司的車（例如副都心線 F 有東京地鐵 10000／17000、東急 5050、西武 40000／6000、東武 50070、相鐵 20000、橫濱高速 Y500）。設定式車款（`jp_*.py`）用 `tools/fleet/jp.py` 的參數化產生器建出；都電、世田谷線、新交通系統與單軌在 `t_special.py`。程序化網格以自身實際寬度顯示（不套路線寬度）。

紐約與早期手寫的幾款：

- `r160`（紐約地鐵 R160）：E、F、FX、J、M、R、Z。單車 18.35 m、寬 2.98 m。車身是不鏽鋼、沒有色帶，只有車頭與側面的路線圓標換成路線色。
- `e233`（JR 東日本 E233 系 0／1000／5000／7000 番台）：JC、JCO、JCI、JK、JE、JA。單車 20 m、寬 2.95 m。窗上、窗下兩道色帶與車頭色塊換成路線色。2000（窄車體）、3000（湘南色）、6000、8000 番台另有網格（`jp_jr.py`）。
- `r62a`（紐約地鐵 R62A）：1、3（R62，外觀幾乎相同）、6、6X、42 街接駁線。單車 15.56 m、寬 2.62 m。車頭整片不鏽鋼；只有路線圓標換成路線色。
- `e235`（JR 東日本 E235 系 0 番台）：JY。單車 20 m、寬 2.95 m。車頭外框與門邊、門上方換成路線色；車頭點狀漸層簡化成三道固定的深淺綠。橫須賀・總武快速線的 1000 番台另有網格。
- `r142`（紐約地鐵 R142；R142A 外觀相近共用）：2、4、5（三個分支）。單車 15.65 m、寬 2.68 m。深藍黑車頭面罩、暗紅燈罩；只有路線圓標換成路線色。
- `e231`（JR 東日本 E231 系 0 番台通勤型）：JJ、JM 等。單車 20 m、寬 2.95 m。前面橫貫路線色帶與側面窗下色帶換成路線色。500、800、1000、3000 番台與 209 系另有網格。
- `r211`（紐約地鐵 R211A／R211T）：A（三個分支）、C、G、S Rockaway。單車 18.35 m、寬 3.05 m。藍色車頭面罩與 LED 頭燈條；只有路線圓標換成路線色。B、D 線也有少量 R211，主力仍是 R68，暫不套用。
- `tm1000`（東京地鐵 1000 系）：G 銀座線。單車 16 m、寬 2.55 m。全車檸檬黃、紅褐色車頂，塗裝固定不換色。
- 中間車網格不放集電弓，因為同一份網格會重複用在每一節中間車。

紐約其他路線（B、D、N、Q、W、L、7、SIR 等）還沒有當地車型的網格，外觀借用軌島台灣版自製的兩款網格，只當示意：

- `c381`（台北捷運 C381 圓弧車頭，不鏽鋼車身）：載入時把藍色帶與紅色車頭飾條換成路線色（`map3d.js` 的 `tintMesh`）。東京地鐵的「不鏽鋼車身＋路線色帶」與此接近；紐約實車沒有色帶，色帶只是為了辨認路線。

加新車型：見 `tools/fleet/README.md`。東京改 `jp_*.py` 後跑 `map_tokyo_fleet.py` 與 `export_world_fleet.py`；紐約改 `formations.js` 的 `WORLD_STOCK`。

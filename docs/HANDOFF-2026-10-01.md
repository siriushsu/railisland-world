## 本機環境

```bash
git clone https://github.com/siriushsu/railisland-world.git && cd railisland-world
git checkout claude/confident-franklin-dv4n5m

# Node（gate 與 App 建置）
(cd app && npm ci)                       # App 依賴，含 playwright
npx --prefix app playwright install chromium webkit
ln -sn app/node_modules node_modules     # 讓 tools/ 底下的腳本解析得到 playwright
echo node_modules >> "$(git rev-parse --git-path info/exclude)"   # 根目錄 node_modules 不在 .gitignore，免得誤 commit

# Python（車型建模；只有改 tools/fleet 才需要）
python3 -m pip install numpy scipy shapely pillow
python3 -m pip install bpy==4.2.0       # 渲染比對圖用（約 500 MB，需 Python 3.11）；裝了 Blender 本體也可以改用 blender -b
```

雲端沒有 WebKit，`verify_world_ui` 的 webkit 欄位是用 Chromium 頂替跑的；**本機請用真的 WebKit 跑一次**。
`tools/` 底下的腳本用 ESM 的 `import` 載入 playwright，Node 的 ESM 解析不讀 `NODE_PATH`，所以要靠上面那個根目錄 `node_modules` 連結；沒有它，`verify_world_ui` 會直接 `ERR_MODULE_NOT_FOUND`。`verify_world_ui` 也可以改設 `RAIL_WORLD_PLAYWRIGHT=<app/node_modules/playwright/index.mjs 的絕對路徑>`，`check_cities`／`check_3d` 則只能靠連結。

## 第一件事：驗證分支上的未驗證 commit

```bash
python3 -m http.server 5188 &                                   # repo 根目錄
node tools/verify_world_ui.mjs                                   # 手機／觸控／雙引擎（chromium＋webkit）
node tools/audit_route_coverage.mjs --release                    # 路線稽核
mkdir -p /tmp/cities && node tools/dev/check_cities.mjs http://127.0.0.1:5188/ /tmp/cities
(cd app && npm run build:verify)                                 # App 建置與 readiness
node tools/dev/check_3d.mjs nyc_sched B /tmp/nyc-b.png           # 抽查 3D（印出模型數與退回原因）
node tools/verify_world_3d_routes.mjs                             # 立體列車的線形與列車位置一致（紐約、東京）
```

全部通過後開 PR 合併到 `main`。

`check_cities.mjs` 只會列出頁面錯誤與 4xx／5xx 請求；原本的 `data/events.json` 404 已在 world-v1002a 修掉（見待辦 5），現在出現任何 4xx 都要查。它會中止所有非 127.0.0.1 的請求，所以截圖沒有街道底圖、東京可能跳出「道路地図を読み込めません」，這是腳本造成的（不斷網時 SwiftShader 也畫得出底圖）。`check_3d.mjs` 的「編組超出已知線形端點」出現在停在終點站的班次，或停在路段所貼線形的端點站（例如 2、5 線停在 Crown Hts-Utica Av，4_Utica 的線形在這站結束），是既有行為。`check_3d.mjs` 的輸出要有 `models` 欄位才代表 3D 有載入；沒有這個欄位時 `fallbacks` 一樣是空的，不能當成通過。本機 `python3 -m http.server` 同時被好幾個瀏覽器存取時會斷線，`map3d.js` 載入失敗就會這樣，重跑或另開一個 port 的伺服器即可。

> 給「軌島・世界」後續 Blender 建模用：每一種車型做一個模型（車頭＋中間車網格，塗裝烘成頂點色），跟台灣版做法相同。本輪只做資料研究，**沒有建模、沒有改程式或資料**。機器可讀版本見同目錄 `catalog-2026-10.json`。

## 範圍與方法

- 範圍：2026 年 10 月的一般旅客列車。排除特急、新幹線、觀光／臨時列車、已退役或試驗車；仍在定期運用但正在汰換的車型保留並標「汰換中」。直通運轉的他社車輛列在它實際會出現的每一條路線上。
- 資料來源：紐約用英文維基百科（含 `Template:NYCS const` 引用的 ERA Bulletin 2025-11 與 NYCT 配車表），東京用日文維基百科各車型條目，2026-10-01 透過 MediaWiki API 擷取。**營運商官網本輪沒有抓取**，所以每筆來源以維基百科為主（條目裡的原始出處可再追）。
- 參考圖片：只收 Wikimedia Commons 上授權為 CC BY／CC BY-SA／CC0／公有領域的檔案，作者與授權取自 Commons extmetadata；沒有下載任何圖片。
- 尺寸：長度為「先頭車／中間車」連結器間長度（紐約為防爬器間），寬度為最大寬或車側燈間寬，高度為車頂／冷氣罩頂（受電弓降下高度另見 JSON）。單位公尺。⚠ 表示部分數值未查證或為推估。
- 顏色：hex 為依照片與文字描述估計，標「（估）」；只有維基條目明列色碼者（例如京成紅藍、E233 各線色帶）才視為較可靠。路線色是否出現在車身寫在 JSON 的 `lineColourUse`。
- 路線欄：**粗體**＝主力車型，斜線後＝少數／直通／部分區間／汰換中。路線代號沿用專案 `data/nyc.json`、`data/tokyo.json` 的 `lines[].id`。

## 缺口與不確定處

- **營運商官網未抓取**：所有規格以維基百科為準；若要「官方規格」需再逐一對照各社車両紹介頁與製造商技報。
- **塗裝 hex 幾乎都是估計值**：紐約車身多為不鏽鋼原色，路線色只在 LED 路線牌；R211 的藍色前端／色帶是憑印象，建模前請對照參考圖。東京各社色帶以文字描述＋路線色推估。
- **紐約 R46**：2026-06 時只剩 N/Q/W 共 140 輛，R211 交車中，2026-10 時可能已大幅減少甚至退出。**R211S 編組輛數**（4 或 5 輛）未查證。**R179 高度**維基值 3.40 m 明顯偏低，未查證。
- **東京 Metro 8000 系**：2026-04-01 只剩 2 編組，2026-10 是否仍定期運用未確認。**07 系**是否仍在東西線運用未確認。**京成 3400 形**剩餘編組未確認。
- **西武**：舊 2000 系 2025-06 退役、新 2000 系 2025-10 起只跑新宿線系統；新 101 系 2026-06 起只剩多摩川線。前東急 9000 系改造的**西武 7000 系**已在狹山線（埼玉縣，不在範圍內）營運，多摩川線／多摩湖線導入時程未確認，故未列入。
- **東武 90000 系**於 2026-09-26 剛投入東上線，外觀、塗裝、是否直通副都心線都還沒查，欄位多標 unverified。
- **東京臨海 71-000 形**（2025-10 起）色帶、**東急 300 系**單車長度、**ゆりかもめ 7500 系**細節、**都營 6500 形**投入日期以外的外觀細節都偏少。
- **直通範圍**：相鐵 20000 系是否定期直通到西武池袋線／東武東上線、京王 5000 系一般列車直通都營新宿線的頻率，只依條目文字判斷，標為 minor。
- **東武 8000 系**已於 2025-07 撤出龜戶線、大師線（改 10030 型 2 輛），故未列入；**JR E217 系**2025-03 退役，橫須賀・總武快速線只剩 E235-1000。
- 參考圖：紐約 13 種都有 2–3 張；東京 28 種只找到 1 張自由授權外觀圖（`tm-13000`、`tm-15000`、`tm-18000`、`toei-5500`、`toei-6500`、`toei-12-600`、`toei-8800`、`toei-9000`、`toei-300`、`toei-320`、`jr-e233-1000`、`jr-e235-1000`、`jr-e231-500`、`jr-e231-3000`、`jr-209-3500`、`jr-e131-500`、`tokyu-5080`、`odakyu-5000`、`keio-9000`、`keio-2000`、`tobu-90000`、`keisei-3200`、`keisei-3400`、`tx-3000`、`mo-10000`、`u-7300`、`u-7500`、`saitama-2000`），東武 90000 系一張都沒有。Commons API 本輪嚴重限流（HTTP 429），補圖搜尋只跑完紐約部分；這些車型請到 Commons 分類手動補。

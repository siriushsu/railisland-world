# 軌島・世界 1.0.0 真機測試表

測試對象是正式簽署後送進 TestFlight／Play testing 的 build，不是桌面瀏覽器或未簽章 archive。每次測試記錄裝置、OS、build number、日期與結果；失敗時附不含個資的畫面與重現步驟。

## 最低裝置矩陣

| 平台 | 最低覆蓋 |
|---|---|
| iOS | 小尺寸 iPhone、一般 iPhone、iPad 各一台 |
| Android | 至少兩個不同尺寸／廠牌，其中一台寬約 360dp；包含目前仍支援的最低或接近最低 Android 版本 |
| 網路 | 正常 Wi-Fi、低速／高延遲、暫時離線後恢復 |
| 外觀 | 淺色、深色、系統自動；直向與橫向 |
| 語言 | 繁中、英文、日文 |

## 每座城市都要做

東京、紐約、倫敦、伊斯坦堡、新加坡各完成一次：

- 城市切換完成，路線、站點、當地時間與移動列車出現，沒有上一城市殘影。
- 縮放、拖曳、全景、搜尋可操作；路線與底圖沒有分層漂移。
- 點一個站看班次；點一班移動列車並跟隨，再停止跟隨。
- 預設密集畫面只顯示彩色圓點／官方縮寫；放大或跟隨後才顯示詳細資訊。
- 畫面明確說明列車為時刻表／班距推演，不是即時位置。
- OpenFreeMap 署名可見；沒有 API key、CARTO 或其他供應商錯誤字樣。

## App 層測試

- 首次啟動、第二次啟動、強制關閉再開啟皆正常。
- 切到背景 30 秒與 5 分鐘後返回，動畫、時間與地圖恢復正常。
- 系統分享面板能開啟；取消分享不會卡住；分享 URL 能在一般瀏覽器開啟。
- 隱私、條款、支援頁在 App 內可開啟，三語切換後內容與方向正常。
- 拒絕或取消外部連結後仍可回到 App；不要求登入、定位、通知或追蹤權限。
- VoiceOver／TalkBack 可讀出主要控制項名稱；Dynamic Type／較大字級不遮住關鍵按鈕。
- 低網速時，路網與列車仍能載入；底圖失敗不應讓 App 無法操作或誤顯成其他供應商。
- 連續切換五城、縮放與跟隨 10 分鐘，沒有 crash、嚴重發熱或持續增加的記憶體異常。

## Google closed test 回饋題目

若帳號需要 12 人／14 天 closed test，請測試者不要只安裝：

1. 最常查看哪一座城市？城市切換是否直覺？
2. 能否分辨「模擬流動」與「即時列車位置」？
3. 密集路線在預設、放大與跟隨三種狀態下是否易讀？
4. 是否遇到空白底圖、卡頓、crash、文字截斷或無法返回？
5. 裝置型號、Android 版本、App build number 與可重現步驟。

測試者必須依 Play Console 規則持續 opt-in；是否達成 production access 以 Console 顯示為準。
